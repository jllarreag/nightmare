# Visual style

## UI (Costume Contest-ready)
- Dark, atmospheric, moody. Deep indigo/near-black backgrounds, soft violet and ember-orange accents.
- Subtle fog/grain animations. Respect `prefers-reduced-motion`.
- Spooky but comforting: the app should feel safe, not scary.
- Accessibility: contrast AA minimum, keyboard navigation, visible focus, captions for audio.
